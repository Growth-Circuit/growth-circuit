# Newsletter issues

One Markdown file per public archive issue. The site lists files here that are not drafts.

1. Copy `emails/newsletter/issue-template.md` to `YYYY-MM-DD.md` in this folder. Use the send date as the filename and `slug`.
2. Fill the four sections: Upcoming Growth Circuit Events (link Growth Circuit), Cool NYC Events This Week, Coming up, Best thing I read this week.
3. Use only public event details and public registration links. Never include guest lists, private Luma or meeting URLs, hidden addresses, or subscriber emails.
4. Keep `draft: true` until the email has been sent. Remove that line (or set `draft: false`) and deploy to publish the archive page at `/newsletter/YYYY-MM-DD`.
