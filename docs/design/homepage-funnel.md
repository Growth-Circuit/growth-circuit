# Growth Circuit homepage funnel

## Creative direction

A 384-character random alphanumeric string was generated locally as the creative seed. Repeated pairs (including OO, RR, MM, and vv), alternating dense and sparse clusters, and the embedded 912 sequence suggested people finding their group, a neighborhood with distinct gathering places, and a three-part participation story. These are creative associations, not evidence about conversion. The string is not included in the page or its assets.

Retain the existing Park Slope illustration as the recognizable centerpiece. Use sky blue #DCEEF5, cloud #F7FCFD, forest #17313A, sage #D6E5D2, and green #355E49. Avenir Next and rounded system headings continue the established identity. Large left-aligned type leads into the neighborhood illustration. Supporting sections stay quieter, with a single event-ticket treatment.

Desktop: navigation / [promise + CTA | neighborhood] / hosts / participation / event invitation / NYC + global applications / FAQ.
Mobile: same reading order, stacked, with native expandable FAQs.

The initial three-equal-path concept created too many competing actions. Revised hierarchy: one primary invitation, “Find your people,” leading to two geographic application choices. Events provide a secondary, lower-commitment way to participate. Unfinished directory features no longer occupy conversion space.

## Implemented

- Explain who the community is for and what members can do before asking them to join.
- Repeat one primary invitation in navigation and hero, anchored to the group choice.
- Include real hosts and their existing affiliation information rather than fabricated member counts or testimonials.
- Keep NYC and global applications clearly distinct and explain review and WhatsApp phone-number visibility.
- Use the verified live application destinations because this checkout's /apply route is an older redirect.
- Link to the live Luma calendar instead of hard-coding a past event as the next event.
- Answer audience, location, solo-attendance, and application questions.
- Preserve existing local artwork. No signup submissions, messages, CRM mutations, or production deployment are part of this preview.

## Recommended next improvements

1. Rebase this design onto the current production branch before publishing. This checkout contains older membership routes and unrelated local edits. Convert the application URLs to relative URLs when the matching live form is present.
2. Measure hero CTA clicks, group selection, application starts, successful applications, and event-calendar clicks. Compare completion per homepage visitor and per group, not raw click totals. Avoid sending application fields or phone numbers to analytics.
3. Add consented event photography and two specific member quotes once available. Prefer a concrete introduction, project, or learning outcome over generic praise.
4. Drive event listings from the live calendar. Show an honest empty state when there are no upcoming dates, and keep past events separate.
5. Keep People + projects secondary until the directory is ready and populated. Member work can later become evidence on the homepage.
6. Test the new headline and application choice against the current page with the same acquisition sources. This is a design hypothesis, not a measured conversion lift.
